tm-rag-copilot

A small, honest demo that embeds a synthetic translation memory and term base, retrieves by meaning, translates with a local model and checks every output with deterministic QA.

简体中文:把虚构的翻译记忆(TMX)和术语库(TBX)向量化存入本地索引,按语义检索最相似的句段,用本地模型生成译文,并用确定性规则逐条做质量检查。

繁體中文:把虛構的翻譯記憶(TMX)和術語庫(TBX)向量化存入本地索引,依語義檢索最相似的句段,用本地模型產生譯文,並以確定性規則逐條進行品質檢查。

What this shows

  • Retrieval over a translation memory: each new string reuses the closest stored segment, so output starts from approved translations instead of being generated from scratch.
  • Deterministic QA that catches model mistakes: every output is checked against its source, and on the real model run it caught the one output that broke a rule (shown in the examples below).
  • Measured experiments only: 6 runs on the same gold set, including one, hybrid keyword search, that made recall worse and was not adopted.

  • Plain vector search, nothing changed: the right match was in the top 10 for 80.5% of queries and ranked first for 51.2%; kept as the reference run, not the default.
  • Keeping only zh-CN units in the ranking lifted the top-10 share to 82.9% and first place to 58.5%; this is the configuration we kept.
  • Adding BM25 keyword fusion to the vector search made recall worse at every k, with the top-10 share falling to 65.8%; it stays an option, not the default.
  • Filter plus hybrid together was strictly worse than the filter alone (top-10 65.8% against 82.9% for the filter only); not adopted.
  • 10 queries written in Chinese, searched against the English sources, still found the right match in the top 10 for 80.0% of them; kept as a standing cross-language check.
  • A real local model (Qwen) passed QA on 97.6% of the 41 items with 0 bad JSON replies, against 80.5% for the retrieval-only mock; kept as the translation path.

What a production system adds

  • A real LLM provider with retries, fallbacks and cost limits (this repo runs one locally: Qwen via Ollama).
  • A versioned TM with metadata (domain, quality scores, last used), per-language collections, and auth on the vector store.
  • Batch and async ingestion, a human review workflow, and terminology enforced during decoding (constrained decoding).
  • Continuous evaluation against a held-out set with alerts when recall or QA pass rate drops.

Limits

  • 133 synthetic segments and a 384-dimensional MiniLM bound retrieval quality; recall@1 stays well below 1.
  • The mock provider copies the nearest TM match; it does not translate. Its QA failures are reported, not hidden.
  • Hybrid BM25 + RRF made recall worse on this paraphrased gold set (measured, kept as an option, not the default).
  • The term base covers zh-CN only; zh-TW and th units exist in the TM but terms are not enforced for them.
  • Qdrant runs in local mode, single process, no concurrency guarantees.
  • Every number on this page is from one run of the committed code on the committed data; deterministic here, not a general claim.
